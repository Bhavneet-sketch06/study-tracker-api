Study Tracker

Simple API for tracking today's study tasks.

Browser → HTTP request → Vercel serverless function → Supabase → JSON response

Available endpoints

GET /api/today-study

Returns today's study tasks and completion summary.


        

      


      
      

        

          POST
          /api/add-task
        

        

          Adds a task for today. Sends { "title": "..." } and stores it with
          completed = false and today's date.
        

        

          
          
        

        
        

          

          

        

      


      
      

        

          GET
          /api/tasks
        

        
Today's tasks including each task's id.

        
        

          

          

        

      


      
      

        

          GET
          /api/hello
        

        
A small test endpoint that confirms the API is running.

        
        

          

          

        

      


      
Data stored in Supabase. Credentials stay on the server.
